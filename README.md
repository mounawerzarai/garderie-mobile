# Ma Garderie

Application mobile de demonstration pour une garderie d'enfants. 

## Technologies utilisees

- Flutter (Dart)
- Git et GitHub

## Installation

// terminal
git clone https://github.com/mounawerzarai/garderie-mobile.git
cd garderie-mobile


## Execution

// terminal
par exemple Windows : `flutter run -d windows`
