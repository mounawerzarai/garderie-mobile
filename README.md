# Ma Garderie

Application mobile de démonstration pour une garderie d'enfants.

## Technologies utilisées

- Flutter (Dart)
- Git et GitHub

## Installation

```bash
git clone https://github.com/mounawerzarai/garderie-mobile.git
cd garderie-mobile
flutter pub get
```

## Exécution

```bash
flutter run
```

Par exemple, sous Windows : `flutter run -d windows`
